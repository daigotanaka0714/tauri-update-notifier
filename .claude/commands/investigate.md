# コードベース調査

ユーザーが指定したトピックについて、コードベースを網羅的に調査する。

## 調査プロトコル

1. **スコープの確認**: 調査対象を明確化
2. **網羅的検索**: ソースコード、設定ファイル、CI/CD、テスト、ドキュメント、スクリプト全てを対象に検索
3. **エビデンスベースの報告**: 各発見に ファイル:行番号 を紐付け
4. **結論の提示**: 明確なYES/NOの判定とエビデンス一覧

## 出力形式
- 結論（1行サマリー）
- エビデンス表（ファイル/行/内容）
- 推奨アクション

## 重要
- 推測と事実を区別する
- 異なるパターンで複数回検索
- タスクエージェントで並列検索
